# Upgrade resource guidance

Cannon, sail and hull upgrade recipes now show exact missing secured resources and one next-action hint. Sources match current loot code: pirate wrecks supply iron; Gunships and Stormjaw supply charts; Stormjaw supplies scales; normal Eastern Reach hunts supply oil. Wreck collection uses E. Materials must be delivered to port.

Carried materials do not count as secured stock. If a required material is in cargo, the hint prioritizes delivery; partial carried amounts are reported without claiming the recipe is complete. Fully funded recipes say ready; Silver-only shortages point to cargo delivery. Empty-selection and +10 behavior is unchanged. No changes to prices, drops, spending, saves or equipment stats.
